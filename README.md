Sistema de Agendamiento - IPS de Rehabilitación

Aplicación de escritorio desarrollada en Python para centralizar y automatizar el agendamiento de citas multiterapia en una IPS de Rehabilitación. Su objetivo principal es reducir la carga administrativa, eliminar los cruces de horarios entre terapeutas y pacientes, y facilitar la generación de cronogramas individuales.
